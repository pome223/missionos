# 海上はAP、市街地で判断を更新する

海上の往復はAPで飛び、市街地に入ってからVLAとWAMを使います。最初は
停止して観測・判断し、短い区間を進んで、到達後にもう一度観測する方式です。
モデルの提案を承認範囲とRulesで確認し、APが移動し、実際の到達を検証します。

市街地から海上へ戻る前に、モデルの処理を終了します。古い判断が遅れて
届いても使いません。省電力の効果は、計算機だけでなく判断待ちのホバリングを
含む行程全体で測ります。

現在は、2回の判断更新、入口の位置確認、通信失敗時の停止、モデル用プロセスの
終了をCPU上の代替モデルとAPで確認する段階です。新しい繰返し制御への
実VLA/WAM・PX4の接続と、実モデルでの市街地内飛行は未完了です。

以前の1 km配送・帰船のシミュレーションでは実モデルを使いましたが、その
判断地点は海岸の約30 m手前でした。この結果を「市街地内での繰返し判断」の
達成として数えません。
