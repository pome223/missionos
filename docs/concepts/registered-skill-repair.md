# Registered-skill Repair

MissionOS can delegate a residual goal to a deterministic registered skill
without describing that skill as a learned model. The runtime keeps diagnosis,
human approval, dispatch, skill execution, and verification as separate facts.

The first LIBERO same-world exercise reached the missing predicate, but the
registered push skill moved a protected object beyond its approved 5 mm bound.
MissionOS stopped the attempt before stable-hold verification and did not claim
completion. This is the intended distinction between **reaching a predicate**
and **completing a bounded Repair**.

The exercise used privileged simulator object state. It does not establish
observation-only Repair, learned-executor Repair, real-world safety, or physical
execution.
