# M3後の帰還シミュレーター診断

M3の管制試験に続き、MissionOSが使う数値計算を8条件で調べました。
ブースターの燃料変化への弱さを再現し、従来の「着地点が77 kmずれる」
現象を、制御の更新間隔と物理計算の刻みに分けて確認しました。

[結果を見る](../assets/starship-recovery-sensitivity-20261012/report.html)

| 調べたこと | 結果 |
| --- | --- |
| ブースター・名目状態 | 保存軌跡と完全一致。接触1.884 m/s、着水条件を通過 |
| 分離時の燃料−1 t | 165.000 m/sで衝突。燃料は81.6 t残った |
| 分離時の燃料＋1 t | 接触1.898 m/s。ただし予備燃料の基準を約793 kg下回った |
| Ship・制御と物理の刻みを同時に変更 | 半分で77.28 km、4分の1で170.44 kmずれた |
| Ship・制御間隔を保ち、物理計算だけ細かくした | 半分で11.76 m、4分の1で6.52 mずれた |

大きな着地点の差は、制御間隔を変えると姿勢の行き過ぎと点火・停止の
タイミングも変わることに強く関係していました。「物理計算の積分誤差が
77 km」とだけ説明するのは不正確です。ただし、今回の1つの出発状態から
一般的な精度保証を出すこともできません。

Shipは保存済み予測に使われた航法推定値からの再計算です。
実際のM3便そのものを飛ばし直した結果ではありません。
ブースターの着水条件はシミュレーター内の判定であり、船体の健全性や
回収・再使用を確認したものではありません。

全条件を先に固定して各1回だけ実行し、失敗も保存しました。
AIの新規呼出しや管制判断の評価は行っていません。
M3で確認した管制経路と、今回分かった誘導の頑健さの不足は別々に扱います。

次は、ブースターの姿勢制御と点火条件の相互作用を直し、燃料±1 tでも
帰還できるかを検証します。Shipでは、制御の時計を物理計算の刻みから
明確に分離してから精度評価を広げます。
