# 予測で経路選択の成否が変わる条件 — 2026-09-25

直進路と迂回路の両方に動く障害物を置き、**単純な予測で到達可能な条件を20件
増やせる場面**をCPUで確認しました。これは合成された運動と時間予算の計算結果です。
WAMの実行、実際の配送、Step 2全体の達成は示していません。

観測誤差がなく、観測した加速度がその後も続く評価540条件では、開発側で選んだ
固定手順「直進して待つ」の432件に対し、加速度予測が452件成功しました。
増加20件、既存成功の喪失0件です。未来を完全に知る理想的選択も452件でした。
等速予測は426件で、改善16件に対して22件の成功を失いました。

ただし、この改善は条件付きです。全ての評価条件を残すと次の結果になります。

| 評価条件 | 条件数 | 固定：直進して待つ | 加速度予測 | 理想的選択 |
| --- | ---: | ---: | ---: | ---: |
| 運動が継続・観測誤差なし | 540 | 432 | **452** | 452 |
| 運動が継続・観測誤差あり | 540 | **432** | 412 | 452 |
| 予告のない運動変化・誤差なし | 540 | **540** | 456 | 540 |
| 予告のない運動変化・誤差あり | 540 | **540** | 494 | 540 |
| 全体 | 2,160 | **1,944** | 1,814 | 1,984 |

誤差は初期の位置履歴に振幅0.25 mの合成波を加えたものです。通行直前の安全確認は
全手法で同じ、正確な現在距離を使っています。障害物を通り抜けて成功扱いにする比較
にはしていません。待機や引き返しにも時間を計上しました。

具体例では、直進路は判断時には空いていても、到着時には塞がります。
直進して待つ手順は37秒の期限に間に合いません。予測を使って迂回を選ぶと、
12.5秒で通行を開始し、36.5秒で計算上の配送・帰還を終えます。この例は等速予測
でも成功します。WAMだけに可能な判断ではありません。

最初の1,152条件では固定手順が成功数の上限に達しました。その結果を残し、
未使用の運動パラメータと細かい期限を固定した追加4,320条件を調べています。
結果を見た後の条件再設計を含む探索で、単一の確認試験ではありません。

前回ANWMの処理時間に相当する41.5秒を待つと、完全な未来情報を与えても全評価で
144 / 2,160件にとどまります。追加GPU実験は見送りました。GPU追加費用は0ドルです。

次に必要なのは、予測が不確かなときの安全側の選択と再観測です。観測誤差がある条件
でも固定手順の成功を失わず、予測が役立つ条件を取り込めるかを確認します。
