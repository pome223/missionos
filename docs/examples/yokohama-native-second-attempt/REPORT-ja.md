# 2回目の市街地実モデル試行：CUDA割当てが残り停止

固定ソース `035e2b53`、run `yokohama-b95aa9e3c929`。D1で30秒保持した後に実モデルを起動しました。AeroVLAは `95 48 38</s>` を生成しましたが、CPUへの退避と循環参照回収の後も9,568,256 bytesのCUDA割当てが残り、応答は拒否されました。VLAの飛行入力推論は1回、WAMは起動のみで飛行入力推論0回、モデル区間の送信・移動は0回です。

今回から短区間飛行の既存条件に合わせて、生成時のyaw範囲を38–60に制限しました。返答の書き換えや推論の再試行は行っていません。最初の失敗とは別条件として保持します。起動応答は172.290秒でした。

モデルとシミュレータの終了を確認しました。同じ上限付きVMを追加診断と別途固定した修正版試行に使ったため、この試行終了の時点でVM削除済みとは扱いません。最終削除・費用は[後続レポート](../yokohama-native-flight/REPORT-ja.md)で確認できます。
