# 次に学習する範囲

今回、出力部分の重みを変えるだけで平均RGB誤差は約47%減りました。
一方、全8件に建物・通路の形状の誤りが残っています。色の誤差だけを
緩めても、現時点で飛行への適用が成立したとは判断できません。

次の候補は、投影した観測と予測画像の対応を扱う
`final_layer.attn` を出力部分と一緒に追加学習することです。
今回この層は固定していました。内部表現の適応が必要という仮説であり、
改善や原因の特定が済んだという意味ではありません。
大規模な再学習を始める前に、対象層・更新回数・費用を限定した試験を行います。

この8件は結果を見たため、次の設計では開発用として扱います。新たな評価地点を
位置で分離して収集し、評価用の実画像をGPUへ渡さず、更新回数と最低条件を
実行前に固定します。学習に使う正解画像と推論に使う過去観測は引き続き分けます。

最小目標は、少なくとも1地点で「停止」と「短い前進」の両方について、
建物・通路を変えずに予測できることです。見栄えやRulesへの優越は求めません。
この条件を満たしてから、市街地内で新しい観測を取り直す短距離飛行を
別の試験として確認します。海上はAPのみという方針を維持します。

この文書は次の設計案です。追加のGPU試験・飛行は実施していません。
今回の累計推定費用は$11.3894、承認済み上限$15までの差額は約$3.61です。
次回は開始時に利用状況を確認し、費用の上限と自動削除を設定します。
