# 横浜：WAMの小規模な事後学習

**小規模な事後学習で平均RGB誤差は36.78から19.66へ減りました。ただし建物・通路の形状の誤りが残り、最低条件を通った地点は0／4です。飛行への適用は未成立です。** 今回は画像予測の追加学習・評価までで、実VLA＋WAMによる飛行は行っていません。

## 小さく学習して成立を確かめる

ANWMの約11.34億パラメーターのうち、最後の出力部分の約269万個（**0.237%**）だけを512回追加学習しました。残りと画像エンコーダーは固定しています。生成画像に後から色を付けた処理ではなく、実際のモデル重みを更新する教師ありの事後学習です。LoRAや強化学習ではありません。保存した重みを読み直してから評価しました。

学習用12地点・24組と、評価用4地点・8組は事前に分け、カメラ位置の間隔を最低18.4 m確保しました。各地点で16枚の新しい停止中のRGBD、1秒後の停止画像、2.8 m先の画像を記録しています。評価用の正解画像はGPUへ送っていません。同じ街区なので、別の場所から同じ建物が見える可能性はあり、未知の街への汎化を示す試験ではありません。

データ収集ではGazeboのカメラを配置し直しています。これは追加学習用の画像収集で、APによる移動や実機飛行ではありません。

## 入力を調べて分かったこと

公開された前処理は画角90°、現在のカメラは60°です。共通の切り出し後では、現在の水平方向の画角は約46.83°になります。色順、正規化、移動量の単位、チェックポイントに必要な16枚の履歴は、既存実装で一致していました。街区の無地の外観や停止中の履歴も、公開データの条件との違いです。これらだけで原因を一意に特定したわけではありません。

モデルの時間条件は秒数でなくフレーム番号の差です。今回の追加学習では「指定した静止視点への1回の遷移」に固定しています。1秒後の運動を予測できるという意味ではありません。[詳細と一次資料](../../agents/yokohama-adaptation.md)

## 評価結果

数値基準を通った画像は、学習前 **0/8**、学習後 **0/8**。停止・前進の両方と目視確認を通った地点は **0/4**でした。学習前後は同じ入力・動作・乱数・推論ステップ数です。

| 区画・動作 | 学習前 MAE | 学習後 MAE | 学習後の大きな誤差 | 数値基準 |
|---|---:|---:|---:|---|
| test-12-hold | 36.18 | 19.18 | 10.6% | fail |
| test-12-forward | 35.73 | 21.45 | 17.9% | fail |
| test-13-hold | 41.86 | 19.72 | 15.3% | fail |
| test-13-forward | 34.60 | 21.28 | 16.9% | fail |
| test-14-hold | 38.90 | 17.98 | 10.5% | fail |
| test-14-forward | 35.62 | 16.95 | 9.9% | fail |
| test-15-hold | 37.81 | 18.46 | 13.9% | fail |
| test-15-forward | 33.59 | 22.26 | 19.6% | fail |


MAEは後続実観測に対するRGB平均誤差（0〜255）。「大きな誤差」は色成分のどれかが40を超えて違う画素の割合です。事前条件はMAE≤15、同割合≤10%、推論≤75秒、存在しない水面や経路を変える建物を生成しないこと。最低1地点で停止・前進の両方を通れば、限定的な適応の成立とします。評価後の条件変更やチェックポイントの選び直しは行っていません。以前の12件の失敗も変更していません。

## 検証と費用

512回の重み更新、固定部分のハッシュ不変、学習部分の変更、保存した重みの再読み込み、学習前後16回の実推論を記録しました。[学習記録](training-receipt.json)・[全更新ログ](training.json)。収集の途中で起きた依存関係不足と位置情報の時刻不整合は、[失敗した収集試行](collection-attempts.json)として残しています。

ローカル全体テストは **3,363件成功**、依存ライブラリ警告3件。公開画像の誤差とハッシュはGPUなしで再計算できます。実行コマンドと確認範囲は[English report](README.md)にまとめました。

```sh
python docs/examples/yokohama-wam-adaptation/verify_bundle.py
```

追加費用は推定 **$0.5112**、累計 **$11.3894 / $15**。請求額は未確定です。GPU VM・ディスクは削除・不在確認済みです。[終了・費用記録](budget.json)

生のセンサーログ、モデル重み、クラウド設定は公開物に含めていません。公開の画像・数値・ハッシュだけで学習全体を独立に再実行できるという主張はしていません。

この試験だけで実VLA＋WAM飛行、配送、海上往復、移動船、強風、10機運用、電力削減が成立したとは扱いません。次は投影観測と予測画像の対応を扱う層まで学習対象を広げる候補を、新たな評価地点で確かめます。[次の学習案](NEXT-ja.md)。予測された建物・通路が最低限使えることを確認してから、新しい観測による短距離飛行を別に検証します。
