# Authored harbour wind profiles

The user-supplied scenario presets are offshore/harbour/coast/city **6/5/4/3 m/s** and **8/7/6/4 m/s**. They are assumptions, not measured Yokohama weather or a validated airframe envelope. City gusts of 8/10/12 m/s are planned, unimplemented and untested.

One CPU fixture sortie with the nominal profile timed out before the coast, 718.02 m from its target. Only the offshore zone was reached. A separate Gazebo transport smoke verified seven seed changes and force responses using a teleported marker; it did not fly a drone. Native VLA/WAM, windy launch, delivery, and return under this profile remain unverified. Incremental GPU cost: $0.
