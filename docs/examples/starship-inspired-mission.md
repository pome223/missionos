# Starship-inspired mission examples

This repository offers two distinct development models. The
[3DOF reference study](starship-3d-simulation.md) uses public observations and
explicit simplifying assumptions. The [coupled 6DOF model](starship-sixdof.md)
integrates attitude, rates, finite actuators, and rigid-body separation.
They are not interchangeable evidence of spacecraft fidelity.

Start with the [MissionOS showcase](starship-mission-showcase.md) for recorded
videos and a bounded fixture through plan, approval, Rules, worker execution,
and saved-record verification. It needs no external API or native simulator.

Both models preserve impacts, time limits, failed objectives, and incomplete
records. A report or record-verification PASS is not successful launch-derived
catch, payload service, physical flight, or an LLM performance result. The
historical reference comparison also does not establish Flight 14 engineering
telemetry or SpaceX control software.

The [source research](starship-research.md) and
[6DOF contract](../agents/starship-sixdof-contract.md) explain these limits.
