# 慎重な初回判断を機上映像と飛行につなぐ

出発時の予測確認を、機上カメラ・PX4・荷物の配送・船への帰還へ接続しました。
固定した3条件×2方式の6試行は、すべて配送と帰還の独立検証に合格しました。

| 障害物 | 通常ルール | 初回判断ゲート |
| --- | --- | --- |
| 短時間で通過 | 待機して直進・完了 | 待機して直進・完了 |
| 長時間の遮蔽 | 迂回・完了 | 迂回・完了 |
| 減速して停止 | 迂回・完了 | 迂回・完了 |

候補側の保存画像で通常ルールを再計算しても、選択は3条件とも一致しました。
接続は確認できましたが、成功数の上乗せや学習済みモデルの追加価値は確認していません。
各条件1回の飛行で生じた小さな時間差から速度向上を主張しません。

[以前のCPU比較](ship-uncertainty-report.md)では二つの動的経路があり、
新規7,560条件で成功が8件増えました。今回の飛行環境は、見える障害物1個と
地図上の迂回路です。履歴の点数・時刻・実行時間も異なります。その8件の改善が
飛行へ移ったとは扱いません。

さらに元の沖合1 kmへ距離を戻した試行では、長距離飛行後のカメラとPX4の
方位差が旧校正範囲を超え、市街地の判断前に停止しました。失敗は保持しています。
校正範囲の拡張を525条件で検算し、最大位置誤差0.188 m、元の6試行の画像観測
44件がすべて同一結果であることを確認してから、通し運転を再実行しました。
修正版では、沖合1 kmと内陸200 mの経路で迂回・配送・帰還の独立検証に合格しました。
元の距離での試行は2回中1回完了で、比較6試行とはバージョンを分けています。

この初回判断は単純な運動モデルを使い、今回VLA/WAMは実行していません。
静止船・1機・既知色の物体を使うシミュレーターでの結果です。移動船への着艦、
実市街地の認識、10機の運用、実機配送は未検証です。

Step 2は、想定環境で必要な性能を満たし、VLAとWAMを使って配送・帰還できることを
達成条件とします。理想化した環境で通常ルールを上回る必要はありません。
今回の比較結果を理由に、モデルの統合を止めたり未達と判定したりしません。
残る確認は、専用WAMの予測が必要な精度・時間で実際の判断に使われることと、
専用VLAを含む全体の動作です。過去の比較結果と失敗記録はそのまま保存します。

入力、判断と実行の区別、再現手順は[検証仕様](../agents/ship-onboard-uncertainty.md)
に記録しました。GPU追加費用は0ドルです。
