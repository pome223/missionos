# 横浜WAM：対応層まで広げた事後学習

**対応層まで追加学習し、平均RGB誤差は18.29から14.98に減りました。数値基準は3／8枚で通過しましたが、通路の表現が曖昧で、目視を含む最低条件は0／4地点です。** 今回は画像予測の追加学習と評価までです。実VLA＋WAMによる飛行は行っていません。

## 何を変えたか

前回は出力部分だけを学習しました。今回は前回の重みから始め、投影した観測と予測画像の対応を扱う層も学習しました。対象は約800万パラメーター、モデル全体の**0.706%**です。残りとVAEは固定しています。学習回数は2,048回、学習率は0.00005に事前固定しました。重みを更新する教師ありの事後学習であり、生成後の画像修正、LoRA、強化学習ではありません。

学習用は前回と同じ12地点で新しく収集した24組です。評価用は新しい4地点・8組で、前回の学習地点・評価地点の両方から最低**16.18 m**離しています。評価の正解画像はGPUへ送っていません。新しい4地点同士は近く、同じ通りや建物が見えるので、独立した4つの環境や未知の街への汎化とは扱いません。

Gazeboの静止カメラで16枚の新しいRGBD履歴、後続の停止画像、2.8 m先の画像を収集しました。カメラの配置変更による収集で、APやドローンが実際に移動した記録ではありません。時間条件の1は、指定した静止視点への1回の遷移を表し、1秒後の運動予測を保証しません。

## 新しい評価地点での結果

比較の「前回の重み」は前回512回学習したモデルです。両条件に同じ新しい観測・動作・乱数を与えました。平均RGB誤差は **18.29 → 14.98**。数値基準を通った画像は **0/8 → 3/8**、停止と前進の両方と目視確認を通った地点は **0/4**でした。

| 地点・動作 | 前回の重み MAE | 今回の重み MAE | 今回の大きな誤差 | 数値基準 |
|---|---:|---:|---:|---|
| test-v2-12-hold | 16.90 | 13.09 | 8.6% | pass |
| test-v2-12-forward | 16.50 | 13.87 | 8.4% | pass |
| test-v2-13-hold | 17.40 | 14.80 | 9.8% | pass |
| test-v2-13-forward | 17.13 | 15.01 | 10.0% | fail |
| test-v2-14-hold | 18.50 | 15.19 | 10.4% | fail |
| test-v2-14-forward | 19.61 | 16.50 | 11.6% | fail |
| test-v2-15-hold | 20.44 | 15.52 | 11.0% | fail |
| test-v2-15-forward | 19.84 | 15.84 | 11.2% | fail |

MAEはRGB平均誤差（0〜255）、大きな誤差は色成分のどれかが40を超えて異なる画素の割合です。最低条件は事前に、MAE≤15、大きな誤差≤10%、推論≤75秒、経路を変える建物や水面を生成しないこととしました。**最低1地点で停止・前進の両方を通ること**だけを目指し、Rulesへの優越は求めていません。

全8件を残し、条件の緩和や評価後の重み選び直しは行っていません。対象層に加えて学習回数も変えたため、差を対応層だけの効果と断定できません。前回の0/4と、それ以前の12件の予測失敗は変更していません。[各画像の目視所見と数値](comparison.json)

## 検証と費用

CPU収集の32組が時刻・位置・学習／評価分離の検証を通過しました。GPU上で2,048回の更新、固定部分のハッシュ不変、学習部分の変化、保存した全テンソルの再読み込み・一致確認、前後16回の実推論を記録しています。[実行条件](protocol.json)・[学習記録](training-receipt.json)・[保存重みの確認](saved-head-audit.json)・[別のCPU処理で確認した各テンソルの変化](parameter-change-audit.json)

ローカルの全体テストは**3,367件成功**、依存ライブラリ警告3件、103.34秒でした。GPUなしで公開画像の誤差・切り出し・ハッシュを再計算できます。これは生ログやモデル重みを使った学習全体の再実行ではありません。具体的なコマンドと確認範囲は[English report](README.md)に記載しています。

追加費用は推定 **$0.5604**、累計 **$11.9498／$15**。請求額は未確定です。GPU VM・ディスクは削除・不在確認済みです。[終了・費用記録](budget.json)

今回の判定だけで、実VLA＋WAM飛行、配送、強風、海上往復、移動船への帰還、10機運用、省電力は成立したと扱いません。海上はAPのみ、市街地でモデルを使う方針を維持します。
