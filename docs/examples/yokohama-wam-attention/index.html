学習用12地点・24組と、新しい評価用4地点・8組を分離しました。新しい評価地点は前回見た全地点から最低16.18 m離れています。同じ街路内の近い4地点による限定的な検証です。GPUには学習用の正解画像を渡し、評価用の正解画像は渡していません。

Gazeboの静止カメラを配置して集めた画像による検証です。前回の重みを出発点に、投影画像との対応を扱う層と出力部分を2,048回学習しました。実VLAの呼び出し、APによる飛行、配送は今回行っていません。時間条件の「1」は1回の指定視点遷移を表し、1秒後を保証しません。
