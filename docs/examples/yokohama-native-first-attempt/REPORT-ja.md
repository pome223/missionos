# 最初の市街地実モデル試行：D1で停止

固定ソース `96b0c3ef`、run `yokohama-1db5e937c115`。D1で30秒保持した後に両モデルを起動しました。AeroVLAは1回推論しましたが、CPUへ戻した後のCUDA割当てが9,568,256 bytes残ったため、ホストが応答を拒否しました。ANWMは起動のみで、飛行観測の推論は0回です。モデル区間の送信・移動・配送・帰還は未達です。

保存された行動は `79 48 0</s>`、前進4.031 m・下方向−0.102 m・旋回−1.1 rad（約−63度）。メモリ条件を除いても、この試験の短区間並進条件 `abs(yaw) < 0.25` を満たしません。出力の補正や同一条件の推論やり直しは行っていません。

起動応答まで167.710秒、VLAホスト応答まで16.427秒でした。保持は継続しましたが、無風の使い捨てSITLを終了した結果であり、実機での中断着陸の検証ではありません。モデルプロセスの終了、GPU計算プロセスの不在、VMとディスクの削除を確認しました。
