# 事前読み込み版の実装と実GPU確認の未完了

同じ公開ANWMをカメラ観測前に読み込む処理を実装した。checkpoint検証を省略せず、同じモデルを最大3要求で使い回す。
入力・モデル設定の不一致、古いworker領域、無効な入力は拒否する。モデルの予測をキャッシュする変更ではない。
実プロセスとfixtureモデルによる2要求の転送確認を含む59件、全体3298件のテストが通った。

実GPU確認は完了していない。最初の試験用VMではworker起動のSSHが60秒でタイムアウトし、
新しい観測入力・モデル予測要求・飛行を始める前に中断した。workerの読み込み完了も確認できていない。
VMと起動ディスクは削除確認済み。起動プロセスを標準入出力とセッションから切り離す方法をローカルで確認した。

この起動失敗を保持し、事前入力段階の再試行を1回だけ試みたが、共有GPU枠が別作業で使用されていた。
10回・各60秒の待機とquota照会に合計609.72秒かかり、VMを作成せず終了した。
登録条件の「10分上限」に対し照会時間分だけ約9.72秒超過した運用上の差を記録する。推論・飛行は0、追加GPU費用も0。
他作業のVMに変更を加えていない。再試行を増やさず、事前読み込みによる実測の速度改善は主張しない。

最初の起動試験は確保から削除確認まで7.91分、保守的見積もり$0.39494。
単一SSH試験終了時の累計$6.44801に加えて、現在の累計は**$6.84295（約$6.84）**の見積もり。
請求明細とは未照合。quota待ちのhelper出力に過去の$4.61が残っていたため、元出力を保持したうえで、
直前の削除確認済み費用を基準に別の照合記録で補正した。新しい請求が発生したという意味ではない。
