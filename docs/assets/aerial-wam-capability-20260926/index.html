判定の範囲

到達、モデルの第一候補が制約を通ったか、要求した動作を実行したかを別々に数えます。迂回で到達しても「ビル間を通過した」ことには数えません。Rulesで第一候補を退けた場合、その変更を表示します。

各場面1回の小規模な既知シーン試験です。手作業で用意した候補経路と目的地画像を使っています。任意経路生成、動く障害物、時間に整合した未来予測、実機飛行、Gatewayの停止・再観測ループへのWAM接続は未検証です。

到達範囲0.3 m・1 sim秒滞在、接触通知0、機体半径0.6 mの外側に25 cm以上の余裕、判断・dispatch時の観測年齢180 wall秒以内、経路120 sim秒／60 m以内。180秒は停止して考える今回の試験上限です。接触通知の無音だけで無接触とせず、記録位置間の線分と建物境界でも検証しています。

再生は出発→目的地のシミュレーション時刻。推論待ちと着陸は再生区間に含めません。到達後の着陸・disarmは別の生ログで確認しています。カメラ欄は各場面4枚の観測画像から近いものを表示します。連続動画ではありません。画像はモデル生成と観測を分けて表示します。
