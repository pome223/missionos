# Starship Flight 14: visual observation ledger

調査日: 2026-10-03。公開映像を標本観察した記録であり、SpaceX の生テレメトリ、
全編レビュー、飛行力学モデルの妥当性検証ではない。

## Source and method

- **公式入口:** [SpaceX Flight 14](https://www.spacex.com/launches/starship-flight-14)
  の `WATCH` をブラウザーで開いた。
- **映像:** [SpaceX official X broadcast](https://x.com/i/broadcasts/1qxvvenMPMQxB)。
  埋め込み URL は `https://studio.x.com/embed/broadcast/1qxvvenMPMQxB`。
  プレイヤーの表示全長は `3:50:53`。表示された発信者は SpaceX / `@SpaceX`。
- **方法:** 公式埋め込みプレイヤーを再生し、一時停止とシークにより下表の画面を
  実見した。`broadcast_time` はプレイヤー経過時間、`mission_time` は映像内の
  `T+` / `T-` 表示を読み取った値。両者を混同しない。約 `35:50` の差があるが、
  表の mission time は各フレームから読み、単なる時刻差の計算で補完していない。
- **遅延処理:** シーク直後に前の映像フレームが残った例がある。画面内 mission
  time とシーク先が食い違う画面は採用せず、更新後の画面を再確認した。
- **精度:** 時刻は秒表示、数値は表示桁までの手読み。表示遅延、丸め、速度の基準座標系、
  高度の基準面、センサー精度は確認できていない。表の値を実機の高精度測定値にしない。
- **保管:** 観察スクリーンショットは調査セッション内にある。動画のダウンロードは
  タイムアウトし、この文書に添付する動画・抽出フレーム・フレームハッシュはない。
  したがってこれは URL とタイムコードで再確認する手動の観察台帳であり、
  ハッシュ固定された校正データセットではない。第三者映像をリポジトリへ転載していない。
- 音声を文字起こししていない。コメントの内容や、観察しなかった区間は映像確認済みと
  しない。Flight 13 や旧世代の映像を Flight 14 の代わりに混ぜていない。

## What the samples support

これらは**観察**からのモデル設計上の示唆であり、機体係数の同定結果ではない。

1. 発射台の静止・点火・離床・上昇を独立したイベントにする。地表に残る白い雲と
   機体に付随する噴炎を別々に描画する。高さを増やすだけでは発射の外観を再現できない。
2. 分離後は Booster と Ship の時間を並行して進める。1本の phase bar だけでは
   Booster 帰還中に Ship が燃焼している状態を隠してしまう。
3. 宇宙空間の姿勢、燃焼の有無、地球の方向、光と影を状態として保持する。
   軌道投入はイベント単位の再点火であり、衛星放出の瞬間と同一ではない。
4. ペイロード放出は側面開口から個別の物体が出て離隔する過程として描く。
   瞬間的に全衛星が所定の円軌道へ現れる演出にはしない。各衛星の release / separation /
   contact / checkout / orbit-raising / customer service を独立させる。
5. 再突入には機体姿勢とフラップ、飛行方向に対する空力、照明を入れる。
   上層大気から着水まで常時エンジンで減速するモデルは、V17～V23 の観測系列の
   校正候補にはならない。具体的な点火条件は別途テレメトリと公表資料で制約する。
6. 低高度の横向き降下、最終点火、フリップ、縦姿勢での減速、海面接触、接触後の状態を
   別イベントにする。splashdown と intact recovery / reuse readiness は別の判定。
7. リプレイは camera source、telemetry age、遮蔽 / 圧縮 / 欠測を表せるようにする。
   配信画像の有無は、機体の状態そのものではない。

## What remains unobserved or uncalibrated

- Booster の全反転、boostback の全燃焼、landing burn と着水の開始・終了は、この
  標本観察では確定していない。公式文章の説明と映像検証を区別する。
- Ship SECO、deorbit burn の開始・停止、26機それぞれの release time、太陽電池展開、
  RF / laser link の確立は、ここでは連続観察していない。
- Catch を示す映像は Flight 14 の本観察にはない。別 flight の catch 映像を参照する場合は
  flight / vehicle generation / tower / outcome のラベルを付け、同一飛行として合成しない。
- 映像だけでは燃料残量、乾燥質量、エンジン推力・絞り率・ジンバル角、慣性テンソル、
  空力係数、熱物性、着水速度、位置精度は同定できない。
- 公式ページの `FLIGHT TIMELINE` は `All Times Approximate` とされた公表表であり、
  本観察の実時刻表ではない。特に同ページに残る約9時間50分の計画と、本映像の
  T+03:08台の海面到達を混ぜない。

## Admission contract for a future calibration dataset

次に「実機映像に合わせた」と主張する前に、以下を満たす小規模な校正セットを作る。

```text
source_url, publisher, flight_id, vehicle_generation, publication_date,
retrieved_at, media_sha256, frame_sha256, broadcast_time_s,
overlay_mission_time_s, camera_id, observable,
overlay_value, overlay_unit, frame_of_reference_or_unknown,
visibility, manual_reading_uncertainty, confidence, review_status
```

- 元動画または合法的に取得した必要最小限のフレームをローカルで固定し、SHA-256 と
  抽出コマンドを記録する。転載権限のない映像を公開デモへ組み込まない。
- カメラ切替、古いフレーム、欠測、表示丸めを含めて各値の採否を記録する。
- 状態遷移は1秒単位の前後フレームで挟み、開始・終了時刻を区間として記録する。
  観察できないイベントは `unknown` とする。
- 速度の ECI / ECEF / ground-relative 定義と高度基準を確認できるまで、
  その表示値を状態ベクトルへ無条件に変換しない。
- モデルを合わせる標本と、別時刻または別 flight の検証標本を分離する。
  V01～V27 の見た目に合わせただけでは独立検証にならない。
- MissionOS は「そのモデルを実行した」「公開映像の特定の observable と一致した」
  「物理モデルが実機で検証された」を別の claim にする。
