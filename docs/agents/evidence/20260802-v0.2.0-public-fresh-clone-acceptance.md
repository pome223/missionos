separates clean-install, deterministic fixture, live simulator, reviewed GPU
evidence, and physical execution instead of reporting one aggregate E2E flag.

## Publication boundary

The release publishes three representative live records: parent three-stage
positive, GR00T/LIBERO positive, and historical freshness rejection. A fourth
small source-audit record is retained because the V2R contract test verifies
that no tracked simulator case is promotion-ready without an explicit physical
target. Historical evidence is never rewritten to match current code.

The GR00T/LIBERO representative is evidence from an earlier cost-capped manual
L4 run. The public fresh-clone acceptance validates its schema, semantic
material compatibility, and claim boundary; it does not rerun an NVIDIA GPU.

## Verdict

`PASS` for publication as a simulator and governance release, subject to green
Python 3.11 and 3.13 CI on the exact public pull request commit.
