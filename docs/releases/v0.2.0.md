# MissionOS v0.2.0

MissionOS v0.2.0 adds a backend-neutral Mission Contract and parent-mission
control plane above three materially different simulator executors:
PX4/Gazebo, TurtleBot3/Nav2/Gazebo, and GR00T N1.7/LIBERO Panda.

The release preserves the authority split:

```text
LLM judges.
Human approves.
Rules constrain.
Executor acts.
Verifier checks.
Repair loops.
```

## Included changes

- Frozen Mission Contracts are separate from runtime Evidence. Observation
  requirements, outcome predicates, quantification scope, termination policy,
  and required verification basis are fixed before execution.
- PX4, Nav2, and LIBERO use concrete versioned predicate packages without
  adding backend-name branches to `missionos-core`.
- Parent missions bind ordered child stages and their pre-existing approval.
  A satisfied stage is a transition prerequisite; it does not create dispatch
  authority or overall mission completion.
- Source and receipt clock domains are explicit and fail closed when they
  cannot be compared or bound.
- Virtual-to-real promotion receipts record which simulator evidence an
  operator used to authorize a bounded target scope. They never prove physical
  safety or sim-to-real equivalence.
- The Control Tower reports frozen inputs, observations, predicates, bounded
  outcomes, transition authority, and unknown or unverified claims separately.
- Approved catalog-backed GR00T/LIBERO missions can be proposed, reviewed, run,
  monitored, and repaired after an episode. Arbitrary free-form tasks remain
  proposal-only until a task-specific capability and predicate package exists.

## Verification matrix

The v0.2.0 gate deliberately does not collapse verification into one green
status:

| Track | Fixture | Reviewed live evidence | Current implementation binding |
| --- | --- | --- | --- |
| PX4 / Nav2 | pass | present | matched |
| Parent mission, three stages | pass | present | matched by post-run source audit |
| GR00T / LIBERO | pass | present | matched by post-run source audit |
| Physical execution | not applicable | absent | not applicable |

The gate compares semantic package material digests, not whole-file hashes.
Historical evidence remains immutable and cannot satisfy a newer package
version after its material changes.

## Public fresh-clone acceptance

The public release candidate is accepted only after a new clone and clean
README installation pass all of the following:

- the complete test suite;
- v0.1.0 and v0.2.0 evidence gates;
- the smoke inventory;
- fixture Gateway HTTP and installed-CLI flow;
- TurtleBot3 house-map projection;
- anonymized two-cycle Recovery replay;
- opt-in PX4/Gazebo and TurtleBot3/Nav2/Gazebo simulator smokes;
- publication-safety scanning; and
- Python 3.11 and 3.13 GitHub Actions.

The detailed result is recorded in

## NVIDIA and third-party boundary

MissionOS does not vendor NVIDIA Isaac-GR00T, LIBERO, model checkpoints, or
third-party simulator source. Public artifacts contain only revisions,
semantic digests, bounded derived facts, and explicit claim boundaries.
GR00T/LIBERO live execution is manual and opt-in; normal CI does not allocate a
GPU or rerun the model.

## Limitations

- All reviewed execution evidence is simulator evidence.
- `physical_execution_invoked=false` remains true for every published record.
- Three satisfied child stages do not establish parent mission completion,
  shared physical-world identity, payload delivery, or operational closure.
- The official LIBERO runner provides no independently observed controller ACK
  or external in-episode stop callback. Readback is not substituted for ACK.
- The reviewed GR00T task is one exact pinned simulator episode, not a success
  rate, benchmark result, or real-world Panda claim.
- Post-episode repair requires a separate human decision and new run identity;
  automatic retry remains forbidden.
