# MissionOS v0.1.0-rc.3

Release candidate validated on 2026-07-23 against public commit
`a52faea58dc2c2c8d83a260d014528469aefe484` before this release-note-only
commit was added. This candidate supersedes `v0.1.0-rc.2`; older RC tags remain
immutable.

## Candidate scope

- Recovery-agent inference runs asynchronously, so live telemetry, obstacle
  detection, and Safety HOLD continue to update while a hosted LLM is working.
- A result whose source context is no longer current is discarded as
  `superseded_retryable`; it cannot silently become a recovery proposal.
- Dispatch-time telemetry arbitration compares the live bridge and runtime
  snapshot cursors and fails closed on an unresolvable or unsafe mismatch.
- Recovery proposals remain separately operator-approved and rule-constrained.
  An LLM result does not itself grant dispatch authority or prove execution.
- DeepSeek V4 remains the primary hosted path in the normal public install.

## Asynchronous inference boundary

The live regression evidence for the async change observed Safety HOLD at
sample 47, continued telemetry updates while inference was pending at samples
48 through 52, and inference completion at sample 53. It proves that the
telemetry loop and HOLD state continued to advance during a live hosted-model
call.

The separate delayed-agent contract test introduces a new obstacle while
inference is pending and verifies that the old result is discarded as
`superseded_retryable`. Its 90-second value is a timeout budget, not a real
90-second sleep; the test releases the controlled inference within five
seconds. These contract and live claims are intentionally kept distinct.

## Publication checks

- The clean install contains no broken or private repository dependency.
- No Python import refers to a private MissionOS or `boiled-claw` package.
- No tracked `.env`, task database, generated output, personal workstation
  path, private Task ID, or live credential was found.
- History hits for token-shaped strings are deliberate anonymization fixtures,
  not credentials; the exported replay contains none of them.
- Generated live evidence and the operator's untracked credential file were
  not added to the public repository.
- Python 3.11 and Python 3.13 CI are required to pass on the release-note PR
  before this tag is published.

## Limitations

- The PX4 run is loopback Gazebo SITL evidence, not real vehicle or hardware
  evidence.
- Operator approvals were explicit and separate. The run does not demonstrate
  approval-free recovery.
- `delivery_completion_claimed=false` remains deliberate: route/dropoff
  observations do not by themselves establish delivery completion.
- `physical_execution_invoked=false` remains deliberate: simulator execution
  is not physical execution.
- The house-map acceptance run is planned fixture geometry with
  `observed_points=0`; it does not claim Nav2 motion.
- Raw TaskStore data, local paths, credentials, and private run identifiers are
  intentionally not published.
